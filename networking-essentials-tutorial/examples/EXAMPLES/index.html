    Networking Essentials - Practical Examples

    This directory contains practical, production-ready examples demonstrating key networking concepts covered in the tutorial.

    Overview

    All examples are containerized for easy reproduction and learning. You can run them locally with Docker and Docker Compose.

    Files Included

    Docker Configuration

    Dockerfile

    A production-grade Dockerfile for containerizing a Flask application with proper networking setup.

    Key Features: - Multi-stage build for optimization - Proper health checks - Non-root user for security - Optimized layer caching

    Usage: 

    docker build -t networking-essentials-app:latest .
docker run -p 5000:5000 networking-essentials-app:latest

    docker-compose.yml

    Complete Docker Compose configuration demonstrating networking concepts including: - Service-to-service communication - Port mapping - Volume management - Network configuration - Environment variables

    Services Included: - Flask application (port 5000) - Nginx reverse proxy (port 80, 443) - PostgreSQL database (optional) - Redis cache (optional)

    Usage: 

    docker-compose up -d
docker-compose logs -f
docker-compose down

    Application Code

    flask-app.py

    A complete Flask application demonstrating: - RESTful API design - HTTP/HTTPS handling - Request/response cycles - Error handling - Security headers - CORS configuration

    Features: - Health check endpoints - API versioning - Structured logging - Error responses

    Usage: 

    pip install -r requirements.txt
python flask-app.py
curl http://localhost:5000/health

    Web Server Configuration

    nginx-docker.conf

    Lightweight Nginx configuration for development/Docker environments.

    Features: - Basic reverse proxy setup - Load balancing configuration - Simple server block configuration - Suitable for local development

    Key Sections: - Upstream backend definitions - Proxy pass configuration - Basic SSL setup

    nginx-production.conf

    Production-grade Nginx configuration with advanced features.

    Features: - Multi-server load balancing - Health checks - Connection pooling - Security headers - SSL/TLS optimization - Gzip compression - Rate limiting - Request logging

    Best Practices Implemented: - Proper upstream health checks - Connection timeouts - Buffer management - Cache-friendly headers - Security-focused headers (HSTS, X-Frame-Options, etc.)

    Usage: 

    # Validate configuration
nginx -t -c /path/to/nginx-production.conf

# Reload with new configuration
nginx -s reload

    Dependencies

    requirements.txt

    Python package dependencies for the Flask application.

    Includes: - Flask - Web framework - Flask-CORS - Cross-origin resource sharing - Gunicorn - Production WSGI server - Requests - HTTP client library - Python-dotenv - Environment variable management

    Installation: 

    pip install -r requirements.txt

    Usage Scenarios

    Scenario 1: Local Development

    Run the Flask app directly with Docker:

    # Build the image
docker build -t flask-app:dev .

# Run with port mapping
docker run -p 5000:5000 \
  -v $(pwd):/app \
  -e FLASK_ENV=development \
  flask-app:dev

# Access the app
curl http://localhost:5000/api/v1/health

    Scenario 2: Docker Compose Stack

    Run the complete stack with Nginx reverse proxy:

    # Start all services
docker-compose up -d

# Flask app: http://localhost:5000
# Nginx: http://localhost

# View logs
docker-compose logs -f flask-app
docker-compose logs -f nginx

# Stop services
docker-compose down

    Scenario 3: Production Deployment

    Use the production Nginx configuration:

    # Copy configuration
cp nginx-production.conf /etc/nginx/conf.d/

# Validate syntax
sudo nginx -t

# Reload configuration
sudo systemctl reload nginx

# Or with Docker
docker run -d \
  -v $(pwd)/nginx-production.conf:/etc/nginx/nginx.conf \
  -p 80:80 -p 443:443 \
  nginx:latest

    Network Concepts Demonstrated

    1. DNS & Name Resolution

    The Flask app includes DNS lookup examples and demonstrates service discovery through Docker's embedded DNS.

    2. TCP/IP Layers

    • Transport layer: Flask runs on TCP port 5000
    • Application layer: HTTP protocol handling
    • Network layer: Docker's internal bridge networking

    3. Load Balancing

    Nginx configuration demonstrates: - Round-robin load balancing - Upstream server management - Connection pooling - Health checks

    4. Reverse Proxy

    Complete example of Nginx as a reverse proxy: - Request forwarding - Backend server hiding - SSL termination - Header manipulation

    5. HTTP/HTTPS

    • HTTP endpoints in Flask
    • HTTPS configuration in Nginx
    • Certificate handling
    • Secure headers

    6. Container Networking

    • Bridge networks
    • Service discovery
    • Port exposure
    • Network isolation

    Security Considerations

    Applied in Examples

    • Non-root Docker containers
    • Security headers (X-Frame-Options, Content-Security-Policy)
    • CORS configuration
    • SSL/TLS termination at proxy
    • Environment variable management
    • Health check endpoints

    For Production Use

    Before deploying these examples to production: - [ ] Update SSL certificates (replace self-signed) - [ ] Configure proper authentication/authorization - [ ] Set up proper logging and monitoring - [ ] Implement rate limiting - [ ] Configure firewall rules - [ ] Use secrets management (not environment variables for secrets) - [ ] Enable security scanning in CI/CD - [ ] Set up intrusion detection

    Troubleshooting

    Port Already in Use

    # Find process using port 5000
lsof -i :5000

# Kill the process
kill -9 <PID>

    Docker Network Issues

    # Inspect Docker network
docker network ls
docker network inspect bridge

# Check service connectivity
docker-compose exec flask-app ping nginx

    Nginx Configuration Errors

    # Validate configuration
docker-compose exec nginx nginx -t
docker-compose logs nginx

    Flask Application Issues

    # Check Flask logs
docker-compose logs -f flask-app

# Access Flask container
docker-compose exec flask-app bash
