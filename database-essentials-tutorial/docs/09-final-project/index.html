    Part 1: Comprehensive Lecture Notes

    Introduction: Bringing It All Together

    In this final module, you'll synthesize everything from modules 1-8 into a production-grade database layer for a real-world application. This isn't just theory—you'll build an actual system demonstrating:

    • Data modeling (Module 4) with proper normalization
    • SQL queries (Module 2) with performance optimization
    • NoSQL design (Module 3) for flexible data structures
    • ORMs (Module 5) with SQLAlchemy relationships
    • Migrations (Module 6) with safe schema changes
    • Performance optimization (Module 7) with indexing
    • Transactions (Module 8) with ACID guarantees and error handling

    Why This Matters

    Mastering databases means: - Build fast systems scaling to millions of users - Sleep at night knowing data is safe and consistent - Deploy confidently with zero-downtime migrations - Handle complex business logic reliably

    Lecture 1: Database Architecture Patterns

    The Three-Database Pattern

    Production systems often use multiple databases, each optimized for specific problems:

    PostgreSQL: OLTP (Relational Transactions) - Complex relationships with ACID guarantees - Strong schema enforcement - Complex queries with JOINs - Example: Users, teams, projects with relationships

    MongoDB: Flexible Documents - Variable-structure data (activity logs, user events) - Nested documents (comments with attachments) - Horizontal scaling - Example: User behavior tracking, flexible metadata

    Redis: Fast Cache & State - Millisecond lookups (microsecond network latency) - Session storage - Rate limiting counters - Example: Cached profiles, authentication state

from flask import Flask
from flask_sqlalchemy import SQLAlchemy
from pymongo import MongoClient
import redis
import json

app = Flask(__name__)
db = SQLAlchemy(app)  # PostgreSQL via SQLAlchemy

# MongoDB for flexible data
mongo = MongoClient('mongodb://localhost:27017')
mongo_db = mongo['task_management']

# Redis for caching
cache = redis.Redis(host='localhost', port=6379)

@app.route('/api/users/<user_id>')
def get_user(user_id):
    # Try cache first (microseconds)
    cached = cache.get(f'user:{user_id}')
    if cached:
        return json.loads(cached)

    # Cache miss - hit PostgreSQL
    user = User.query.get(user_id)  # Relational: strong constraints

    # Get activity logs from MongoDB (flexible structure)
    activities = list(mongo_db.activities.find({'user_id': int(user_id)}))

    result = {
        'user': user.to_dict(),
        'activity_count': len(activities),
        'last_activity': activities[0] if activities else None
    }

    # Store in cache (1 hour TTL)
    cache.setex(f'user:{user_id}', 3600, json.dumps(result))

    return result

    Lecture 2: Data Modeling from Requirements

    Step-by-Step Process

    1. Identify Entities from Requirements

    Requirement: "Build a task management system where teams have projects with tasks"

    Entities: - User (person using system) - Team (group of users) - Project (work collection within team) - Task (individual work item) - Tag (categorization) - Activity (history/audit trail)

    2. Map Relationships

    User
  ├─ creates 1 to many Team
  ├─ belongs to many Team (many-to-many)
  ├─ assigns many Task
  └─ creates many Activity

Team
  ├─ has many User (many-to-many)
  └─ has many Project

Project
  ├─ belongs to 1 Team
  └─ has many Task

Task
  ├─ belongs to 1 Project
  ├─ assigned to 1 User (nullable)
  ├─ created by 1 User
  └─ has many Tag (many-to-many)

    3. Normalize to 3NF (Third Normal Form)

    -- WRONG (Denormalized - data duplication)
CREATE TABLE tasks (
    id INT PRIMARY KEY,
    title VARCHAR(255),
    project_name VARCHAR(255),      -- DUPLICATE!
    assigned_to_email VARCHAR(255), -- DUPLICATE!
    assigned_to_name VARCHAR(255)   -- DUPLICATE!
);

-- RIGHT (Normalized - single source of truth)
CREATE TABLE tasks (
    id INT PRIMARY KEY,
    title VARCHAR(255),
    project_id INT REFERENCES projects(id),  -- Just foreign key
    assigned_to INT REFERENCES users(id)     -- Just foreign key
);

-- When project name changes: Update 1 row in projects
-- When user email changes: Update 1 row in users
-- Consistent data across entire system

    Lecture 3: Query Optimization & Pattern Recognition

    Pattern 1: The N+1 Query Problem

    # SLOW: N+1 Queries (1 initial + N per item)
def get_all_tasks_slow():
    tasks = Task.query.all()  # 1st query

    result = []
    for task in tasks:
        result.append({
            'id': task.id,
            'title': task.title,
            'assigned_to_email': task.assigned_to.email  # N more queries!
        })

    return result
    # Total: 1 + 100 = 101 queries
    # Time: 5 seconds (if 50ms per query)

# FAST: Eager loading with single JOIN
def get_all_tasks_fast():
    from sqlalchemy.orm import joinedload

    tasks = Task.query.options(
        joinedload(Task.assigned_to)  # JOIN users in single query
    ).all()

    result = []
    for task in tasks:
        result.append({
            'id': task.id,
            'title': task.title,
            'assigned_to_email': task.assigned_to.email if task.assigned_to else None
        })

    return result
    # Total: 1 query with JOIN
    # Time: 100ms (50x faster!)

    Lecture 4: Transaction Patterns for Safety

    Pattern 1: Pessimistic Locking

    def transfer_task_ownership(task_id, new_owner_id, updated_by_id):
    """Lock prevents concurrent modifications"""
    with db.session.begin():
        # Lock this task from other transactions
        task = Task.query.with_for_update().get(task_id)

        if not task:
            raise ValueError("Task not found")

        old_owner = task.assigned_to
        task.assigned_to = new_owner_id
        db.session.flush()

        # Log to MongoDB
        mongo_db.activities.insert_one({
            'user_id': updated_by_id,
            'action': 'task_transferred',
            'task_id': task_id,
            'from_user': old_owner,
            'to_user': new_owner_id,
            'timestamp': datetime.utcnow()
        })

    # Both writes atomic (both succeed or both fail)

    Pattern 2: Optimistic Locking

    class Task(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    title = db.Column(db.String(255))
    version = db.Column(db.Integer, default=1)  # Version field

def update_task_optimistic(task_id, current_version, new_data):
    """Detect conflicts instead of preventing them"""
    with db.session.begin():
        result = db.session.query(Task).filter(
            Task.id == task_id,
            Task.version == current_version
        ).update({
            Task.title: new_data['title'],
            Task.version: current_version + 1
        }, synchronize_session=False)

        if result == 0:
            raise ValueError("Task was modified. Please refresh.")

        return result == 1

    Pattern 3: Idempotent Operations

    def create_task_idempotent(idempotency_key, project_id, title):
    """Safe retries without duplicates"""
    with db.session.begin():
        # Check if already processed
        existing = db.session.query(TaskCreationKey).filter(
            TaskCreationKey.key == idempotency_key
        ).first()

        if existing:
            return Task.query.get(existing.task_id).to_dict()

        # New request: create task
        task = Task(project_id=project_id, title=title)
        db.session.add(task)
        db.session.flush()

        # Record processing to prevent duplicates
        key = TaskCreationKey(key=idempotency_key, task_id=task.id)
        db.session.add(key)
        db.session.commit()

        return task.to_dict()

    Index Selection Strategy

    -- Rule: Equality first, then ranges, then sorting
-- Pattern: WHERE a = ? AND b < ? ORDER BY c

CREATE INDEX idx_tasks_optimized 
    ON tasks(assigned_to, due_date, status);

-- Satisfies:
-- 1. WHERE filtering (assigned_to, due_date)
-- 2. STATUS filtering (included in index)
-- All in one efficient lookup!

from datetime import datetime
from sqlalchemy.orm import relationship

class User(db.Model):
    __tablename__ = 'users'

    id = db.Column(db.Integer, primary_key=True)
    email = db.Column(db.String(255), unique=True, nullable=False, index=True)
    password_hash = db.Column(db.String(255), nullable=False)
    full_name = db.Column(db.String(255), nullable=False)
    is_active = db.Column(db.Boolean, default=True)
    is_verified = db.Column(db.Boolean, default=False)
    created_at = db.Column(db.DateTime, default=datetime.utcnow)
    updated_at = db.Column(db.DateTime, default=datetime.utcnow, onupdate=datetime.utcnow)

    # Relationships (no N+1: lazy load only when needed)
    owned_teams = relationship('Team', foreign_keys='Team.owner_id', backref='owner')
    assigned_tasks = relationship('Task', foreign_keys='Task.assigned_to', backref='assignee')
    created_tasks = relationship('Task', foreign_keys='Task.created_by', backref='creator')

    def to_dict(self):
        return {
            'id': self.id,
            'email': self.email,
            'full_name': self.full_name,
            'is_active': self.is_active,
            'created_at': self.created_at.isoformat()
        }

# models/task.py
class Task(db.Model):
    __tablename__ = 'tasks'

    id = db.Column(db.Integer, primary_key=True)
    project_id = db.Column(db.Integer, db.ForeignKey('projects.id', ondelete='CASCADE'), nullable=False, index=True)
    title = db.Column(db.String(500), nullable=False)
    description = db.Column(db.Text)
    status = db.Column(db.String(20), default='todo', nullable=False, index=True)
    priority = db.Column(db.String(20), default='medium', nullable=False, index=True)
    assigned_to = db.Column(db.Integer, db.ForeignKey('users.id', ondelete='SET NULL'), index=True)
    due_date = db.Column(db.DateTime, index=True)
    created_by = db.Column(db.Integer, db.ForeignKey('users.id'), nullable=False)
    version = db.Column(db.Integer, default=1)  # For optimistic locking
    created_at = db.Column(db.DateTime, default=datetime.utcnow)
    updated_at = db.Column(db.DateTime, default=datetime.utcnow, onupdate=datetime.utcnow)

    # Relationships
    project = relationship('Project', backref='tasks')

    def to_dict(self):
        return {
            'id': self.id,
            'title': self.title,
            'status': self.status,
            'priority': self.priority,
            'assigned_to': self.assigned_to,
            'due_date': self.due_date.isoformat() if self.due_date else None,
            'created_at': self.created_at.isoformat()
        }

    Repository Layer (Data Access)

    # repositories/task_repo.py
from sqlalchemy.orm import joinedload

class TaskRepository:
    """Repository for Task database operations"""

    @staticmethod
    def create_task(project_id, title, description, created_by_id):
        """Create task with transaction and audit logging"""
        with db.session.begin():
            task = Task(
                project_id=project_id,
                title=title,
                description=description,
                created_by=created_by_id
            )
            db.session.add(task)
            db.session.flush()

            # Log activity to MongoDB
            mongo_db.activities.insert_one({
                'user_id': created_by_id,
                'action': 'task_created',
                'task_id': task.id,
                'metadata': {'title': title},
                'timestamp': datetime.utcnow()
            })

            return task

    @staticmethod
    def get_project_tasks_optimized(project_id, filters=None):
        """Get tasks with eager loading (prevents N+1)"""
        query = Task.query.filter(
            Task.project_id == project_id
        ).options(
            joinedload(Task.assigned_to),
            joinedload(Task.project),
            joinedload(Task.creator)
        )

        if filters:
            if 'status' in filters:
                query = query.filter(Task.status == filters['status'])
            if 'priority' in filters:
                query = query.filter(Task.priority == filters['priority'])

        return query.all()

    @staticmethod
    def update_task_optimistic(task_id, current_version, data):
        """Update task with optimistic locking"""
        with db.session.begin():
            result = db.session.query(Task).filter(
                Task.id == task_id,
                Task.version == current_version
            ).update({
                Task.title: data.get('title'),
                Task.status: data.get('status'),
                Task.version: current_version + 1,
                Task.updated_at: datetime.utcnow()
            })

            if result == 0:
                raise ValueError("Task was modified by another user")

            return result == 1

    Service Layer (Business Logic)

    # services/task_service.py
import json
from datetime import datetime

class TaskService:
    """Service layer with business logic and caching"""

    def __init__(self, redis_client):
        self.redis = redis_client
        self.repo = TaskRepository()

    def get_project_tasks(self, project_id, use_cache=True):
        """Get tasks with Redis caching"""
        cache_key = f'project:{project_id}:tasks'

        # Try cache first
        if use_cache:
            cached = self.redis.get(cache_key)
            if cached:
                return json.loads(cached)

        # Cache miss - fetch from DB
        tasks = self.repo.get_project_tasks_optimized(project_id)
        result = [task.to_dict() for task in tasks]

        # Store in cache (1 hour TTL)
        self.redis.setex(cache_key, 3600, json.dumps(result))

        return result

    def create_task(self, project_id, title, description, created_by_id):
        """Create task and invalidate cache"""
        task = self.repo.create_task(
            project_id=project_id,
            title=title,
            description=description,
            created_by_id=created_by_id
        )

        # Invalidate project cache
        self.redis.delete(f'project:{project_id}:tasks')

        return task.to_dict()

    def assign_task(self, task_id, user_id):
        """Assign task with pessimistic locking"""
        with db.session.begin():
            task = Task.query.with_for_update().get(task_id)
            if not task:
                raise ValueError("Task not found")

            task.assigned_to = user_id
            db.session.flush()

            # Log to MongoDB
            mongo_db.activities.insert_one({
                'action': 'task_assigned',
                'task_id': task_id,
                'assigned_to': user_id,
                'timestamp': datetime.utcnow()
            })

            # Invalidate cache
            self.redis.delete(f'project:{task.project_id}:tasks')

        return task.to_dict()

        # 4. Create task
        task = task_service.create_task(
            project_id=project_id,
            title='Design homepage',
            description='Create beautiful homepage',
            created_by_id=user_id
        )

        # 5. Query tasks efficiently (single query with JOINs)
        tasks = task_service.get_project_tasks(project_id)
        print(f"Found {len(tasks)} tasks")

        # 6. Assign task with pessimistic lock
        assigned_task = task_service.assign_task(task['id'], user_id)
        print(f"Task assigned to user {assigned_task['assigned_to']}")

        return {
            'user': {'id': user_id},
            'project': {'id': project_id},
            'task': assigned_task
        }

    -- Users
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    email VARCHAR(255) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    full_name VARCHAR(255) NOT NULL,
    is_active BOOLEAN DEFAULT TRUE,
    is_verified BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX idx_users_email ON users(email);

-- Teams
CREATE TABLE teams (
    id SERIAL PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    owner_id INTEGER NOT NULL REFERENCES users(id),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX idx_teams_owner ON teams(owner_id);

-- Projects
CREATE TABLE projects (
    id SERIAL PRIMARY KEY,
    team_id INTEGER NOT NULL REFERENCES teams(id),
    name VARCHAR(255) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX idx_projects_team ON projects(team_id);

-- Tasks  
CREATE TABLE tasks (
    id SERIAL PRIMARY KEY,
    project_id INTEGER NOT NULL REFERENCES projects(id) ON DELETE CASCADE,
    title VARCHAR(500) NOT NULL,
    description TEXT,
    status VARCHAR(20) DEFAULT 'todo',
    priority VARCHAR(20) DEFAULT 'medium',
    assigned_to INTEGER REFERENCES users(id) ON DELETE SET NULL,
    due_date TIMESTAMP,
    created_by INTEGER NOT NULL REFERENCES users(id),
    version INTEGER DEFAULT 1,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Composite index for common queries
CREATE INDEX idx_tasks_project_status_priority 
    ON tasks(project_id, status, priority);
CREATE INDEX idx_tasks_assigned_to ON tasks(assigned_to);
CREATE INDEX idx_tasks_due_date ON tasks(due_date) 
    WHERE due_date IS NOT NULL;
